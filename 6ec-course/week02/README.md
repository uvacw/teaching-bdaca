### Chapter 5: From file to dataframe and back
In this chapter, we discuss file formats such as `CSV` and `JSON`, including:

- Understanding **encodings**.
- Reading these formats into basic Python structures, such as **dictionaries** and **lists**, as opposed to reading them into **dataframes**.
- Retrieving data from local files, as parts of packages, and via an **API**.

We will explore how to handle file formats and interact with APIs for data manipulation.
