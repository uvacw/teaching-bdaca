# Week 4: Working with textual data

Both notebooks are in this folder:

- [Assignment](pre-processing.ipynb)
- [Solutions](pre-processing-solutions.ipynb) — check these after trying the tasks.

Work through four short parts:

1. Clean a list of texts.
2. Count word mentions with regular expressions.
3. Tokenise a text and consider which stopwords to remove.
4. Read a document-term matrix and try bigrams and trigrams.

The small news-text dataset is included in the notebook. Stemming and
lemmatisation at the end are optional.
